## 学習概念

最小 UI から在庫更新・承認操作を行い、API Gateway（または同等）とワークフローをつなぐ。  
保護の境界（ブラウザに秘密を出さない）を学ぶ。

## 範囲

前提: [v0.2.0](v0.2.0.md) の承認と占有。

### 画面（最小）

- 在庫一覧、現在在庫の更新
- 補充リクエストの状態表示
- 承認 / 却下
- 静的 HTML + 最小 JS。凝った装飾なし
- 非負整数の入力、送信中 / 失敗 / 再読込、期限切れ・競合の表示
- 承認待ち以外の decision は UI とサーバーの**両方**で拒否
- **e2e シナリオ**（npm パッケージ `e2e` + `@e2e-dev/web`）あり。`mise exec -- npm run test:e2e`

### API（確定）

| 方法 | 用途 | 保護 |
| --- | --- | --- |
| `GET /items` | 品目一覧 | `X-Approval-Secret` |
| `PUT /items/{id}/stock` | 現在在庫更新 | 同上 |
| `GET /restock-requests` | 補充リクエスト一覧 | 同上 |
| `POST /items/{id}/restock-requests/{streamEventId}/decision` | 承認または却下 | 同上（v0.2） |

ブラウザはこれらを直接呼ばない。localhost 中継が同じ origin の `/api/*` を受け、必要なら上流へ秘密付きで中継する。

### 保護（採用）

**採用:** 1 人用・localhost 同一 origin 中継。理由と不採用案は [v0.3.0-design.md](v0.3.0-design.md)。  
CORS を認証と扱わない。AWS 秘密・task token をブラウザ応答・HTML・URL に出さない。
