## 学習概念

Step Functions の Retry・Catch・Wait（日時）。  
意図的に失敗する模擬注文と、画面上の進行状態表示。

## 範囲

前提: [v0.3.0](v0.3.0.md) の画面と承認済みフロー。

- 模擬注文 Lambda。一時失敗と継続失敗を**決定的に**再現できる入力/設定を持つ
- 一時失敗 → Retry で回復
- 継続失敗 → Catch で別経路（取消の骨格。補償の完成は [v0.5.0](v0.5.0.md)）
- 注文成功後、到着予定まで日時 Wait（検証では短縮してよい）
- 到着確認ステップへ進むところまで
- 画面に「注文中」「配送待ち」「失敗」など進行状態を出す

## 非範囲（この版）

- 補償（注文取消→リクエスト取消）の完成と冪等（→ v0.5.0）
