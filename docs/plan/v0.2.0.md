## 学習概念

要件 **3・8**。`.waitForTaskToken`、timeout 却下、条件付き占有/解放、Streams の部分失敗報告。

## 範囲

前提: [v0.1.0](v0.1.0.md)。

1. 承認待ちで止まり、承認 API（画面なし）で再開する
2. 一定時間無応答は却下（`ApprovalTimeoutSeconds` で短縮可）。在庫は変えない
3. `sk=LOCK` の条件付き占有で実行中は品目あたり1本
4. 起動失敗時は占有解放。Streams は `ReportBatchItemFailures` + bisect + 再試行上限
5. 期限切れ・再送・競合 decision は 409 等で拒否
